# QA-523 · Un solo modelo de embeddings: hechos del mundo con bge-m3

## Goal

Los hechos del mundo se embeben con bge-m3, como el lore, para que el turno no turne dos modelos de embeddings en la memoria.

## Scope

Columna, modelo por defecto, re-embebido de lo existente y sus usuarios (entorno, scripts, docs de instalación). Fuera: medición en la Deck y juego de casos de hechos.

## Acceptance

- [x] Sin variable, los hechos y el lore usan bge-m3 (`backend/src/config/env.test.ts`).
- [x] La columna admite 1024, el texto se conserva y repetir el re-embebido no hace nada (`backend/src/services/worldFacts.integration.test.ts`).
- [x] Un hecho sin vector no rompe la selección (`worldFacts.integration.test.ts`).
- [x] El re-embebido va por lotes y, si Ollama falla, conserva lo hecho (`backend/src/services/worldFacts.test.ts`).
- [ ] Medido en la Deck: `bench-ia.sh` y `loaded runners count=3` sin recargas.
- [ ] Juego de casos de hechos.
