ESCRIBE

Necesito 1 item EQUIPABLE para los Orcos de las Llanuras del Viento Rojo

CONTEXTO:
- Trabaja solo con lo que ya has leído. NO leas nada nuevo.

CADA ITEM debe incluir:
- Nombre común en español (2-3 palabras)
- Nombre propio en la lengua de la raza solicitada
- Tipo: EQUIPABLE / CONSUMIBLE / MATERIAL / RECURSO / NARRATIVO / ESPECIAL
- Categoría (uno de):
  · Equipo: arma / ropa / herramienta
  · Consumibles: consumible / medicinal / alimento
  · Materiales: material / recurso / bloque / metal / viga / columna / cordaje / madera / mena / piedra / piel / pluma / quitina / resina / escamas / cera / cuerno / garra / pelo / fibras / hueso / hierba / planta / filtro
  · Narrativos: documento / especial / cosmetico / valor / narrativo
- Si es EQUIPABLE, ranura: ARMA_PRINCIPAL / ARMA_SECUNDARIA / CASCO / ARMADURA_SUPERIOR / ARMADURA_INFERIOR / GUANTES / BOTAS / CINTURON / CAMISA / ANILLO_1 / ANILLO_2 / ACCESORIO / COSMETICO_CINTURA / COSMETICO_ESPALDA / CONSUMIBLE_1
- Si es ARMA, tipoArma: ESPADA_1_MANO / HACHA_1_MANO / MAZA_1_MANO / GARROTE_1_MANO / DAGA / CUCHILLO / LANZA / PICA / ESCUDO / BACULO
- Si es ARMADURA, pesoArmadura: LIGERO / MEDIO / PESADO
- Si es EQUIPABLE, bonificadores: qué atributo(s) sube y cuánto (escala 1-5), o "defensa" o "inventorySlots"
- Función concreta
- Descripción detallada: física: forma, tamaño, materiales
- Dimensiones concretas (cm)
- Lugar de origen
- Tier (1-9) y valor en Goirnos
- Requisitos de equipar (fuerza, destreza, constitución mínimos)
- Si es consumible o medicinal: cuánto cura (hasta GRAVE / HERIDO / ILESO), energía, agua, hambre
- Si es herramienta: para qué oficio sirve

NO QUIERO:
- Items mágicos sin fundamento
- Stats inventados que no encajen con el tier
- Materiales que no aparezcan en lo leído
- Campos que no haya pedido
- Más de 250 palabras por item
