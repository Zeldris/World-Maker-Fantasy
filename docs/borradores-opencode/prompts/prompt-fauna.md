PASO 2 — ESCRIBE
───────────────────────────────────────────────────────────────

ESCRIBE

Necesito 1 fauna para el Margen Silencioso.

CONTEXTO:
- Trabaja solo con lo que ya has leído. NO leas nada nuevo.
- Zona concreta:  Margen Silencioso

CADA CRIATURA debe incluir:
- Nombre común en español (2-3 palabras)
- Nombre propio en la lengua de la raza solicitada
- Artículo (el / la) — solo para nombres descriptivos de rol; omitir si es nombre propio
- Género (M / F) — solo si el nombre o la bio lo dejan claro
- Rol ecológico (depredador / presa / carroñero / parásito / simbionte)
- Categoría de fauna (uno de): GUELISES jauría / CORVENES ave / ACECHANTES solitario / BESTIONES grande de manada / ZANCUDOS corredor / QUITINOS acorazado / MUDOS_SALVAJE mutado / ESCAMADOS reptil / NADANTES acuático / RONDINES roedor
- Nivel base y nivel máximo (1-30)
- Atributos (escala 1-20): fuerza, destreza, constitucion, inteligencia, voluntad, carisma, magia
- Descripción física detallada: tamaño (en cm), aspecto, comportamiento
- Hábitat concreto (Location exacta donde vive)
- Medio de movimiento (TERRESTRE / AEREO / ACUATICO — puede tener más de uno, ej: anfibio)
- Temperamento (AGRESIVO / CAUTELOSO / INOFENSIVO)
- Ataque natural (frase corta)
- Porcentajes (0-100): domesticable, capturable
- Relación con los habitantes de la zona
- Comportamiento y habitos

NO QUIERO:
- Especies reales conocidas
- Mecánicas inventadas (stats de daño, drops)
- Materiales que no aparezcan en lo leído
- Campos que no haya pedido
