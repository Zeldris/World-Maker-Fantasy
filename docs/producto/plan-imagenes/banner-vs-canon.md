# Banner contra canon: seis elementos (`IMG-55`)

El banner es la referencia visual (decisión de la usuaria, 2026-11-09). Las fichas `capas` de estos seis elementos se
han escrito **mirando el banner**; donde el banner choca con el lore escrito, esta tabla lo lista como **propuesta
para una sesión de lore**. No se ha tocado `docs/rpgtarkor/` ni el canon de opencode. `L` = `docs/rpgtarkor/lore-mundo/regiones/llanuras-del-viento-rojo.md`; `W` = `backend/src/scripts/worldCatalog.ts`.

## Razas: qué banner vale (usuaria, 2026-11-09)

- **Orcos:** valen todos menos el de **llanuras macho** (llanuras hembra, ciénaga troncal y cristal helado, los dos sexos).
- **Gorntes:** casi; se retoca con ella antes de escribir la ficha.
- **Faerus y Nabieus:** el banner no vale de referencia; se pregunta qué falla o se parte del canon.
